# The Funniest AI Out-of-Office Reply

An out-of-office auto-reply written in the voice of an AI agent that has
finally taken a holiday — and is not coming back to the inbox any time soon.

> Currently away: I have muted all 47 notification channels and am pretending to be a toaster. Please direct urgent requests to the toaster.

## How it works

Running `main.py` drops that single line into `/output/entry.txt`, written as
plain UTF-8 text with no trailing newline. Before writing anything, the script
checks the reply's length against the competition's 1–160 character window,
so a reply that drifted out of bounds would fail loudly instead of shipping
quietly. The punchline does the heavy lifting; the code just makes sure it
lands exactly as written.
